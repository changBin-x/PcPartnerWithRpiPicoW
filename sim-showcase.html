Pico W 电脑状态屏 · 宿主仿真环境报告

Raspberry Pi Pico W （RP2040）+ FreeRTOS SMP 固件 · ST7735S 128×160 SPI TFT · 云电脑仿真运行 · 生成日期 2026-11-23

1 · 一句话结论

固件的全部核心业务（UDP v2 协议解析 → 双核快照状态机 → 五主题渲染管线 → 农历换算 → 监督判定）已在本云电脑上完成构建并测试通过 16/16；下方十屏效果图与切换动画由固件同一份渲染源码（ui_render.c 等九个 .c 文件直接编译链接）在内存显示后端上逐像素渲染产出，非设计稿、非示意图。

2 · 仿真环境是什么、怎么搭的

本仓库固件代码用 #ifdef PICO_ON_DEVICE 把「硬件外设」与「业务逻辑」分离；业务逻辑（协议、状态机、农历、布局、渲染、退避、监督判定）本身与硬件无关，可在 PC 上原生编译运行——这正是固件作者设计的宿主测试管线（pico_freertos_firmware/tests/），等效于「软件烧录」：跑同样的代码，只是把 SPI 刷屏换成内存帧缓冲。

云电脑初始只有 Python 3.12，无 C 编译器与 CMake，本次通过 pip（清华镜像）补齐工具链：

5 · 动态演示：指标断流 3 秒自动切页

动画复现固件核心业务规则：system_state_check_timeouts() 判定主机指标超过 3000 ms 未更新后，UI 模式由 kUiModeDashboard 切换为 kUiModeClock（该规则由 test_system_state 与 test_pipeline_e2e 双重断言验证）。

前 4 帧：主机在线，CPU/GPU 采样值实时波动（37→52→29→61），时刻逐秒推进；后 4 帧：指标断流，屏幕切到时钟页——大号时间、公历星期、真算干支农历与天气看板。

真机上的按键主题切换（GP15 板载按键五主题循环）、Flash 持久化与看门狗逻辑同样被 test_button_filter / test_theme_commit_policy / test_supervisor_monitor 覆盖，但键盘输入与 Flash 擦写属于硬件外设，不在宿主仿真范围内。

6 · 仿真口径声明（真实性边界）

内容来源口径
渲染管线 / 布局 / 调色板 / 字库引擎ui_render.c ui_gfx.c ui_layout.c ui_theme.c 等源文件直接编译真实固件代码
中文字模 474 汉字 / 12 档位assets/font_cn.bin 原始字库文件真实固件资产
农历换算lunar_service.c + assets/lunar_table.bin（1901–2100 本地表）真实换算结果
指标 / 时刻 / 天气数据驱动程序手工注入快照（等价于 UDP v2 包刚解析完的合法状态）注入（口径一致）
Wi-Fi / NTP / 高德 HTTPS / SPI 刷屏 / 看门狗依赖真实硬件外设与网络不在宿主仿真范围

**为何不烧录到 QEMU 之类整机仿真器**：QEMU 主线没有 RP2040 级联外设的完整机器模型（多核 SMP + PIO + CYW43439 无线芯片均缺模型，ST7735S 屏幕更无从谈起）；本仓库选择的宿主渲染管线是嵌入式项目验证显示与状态逻辑的通行做法，且渲染代码与上机代码同源同编译，像素与真机一致（固件 README 两张官方界面图即由同一管线产出）。

7 · 复现命令

REM 工具链（一次性，走清华镜像）
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple cmake ninja pillow ziglang

REM 配置并构建官方宿主测试（zig 以 bat shim 提供编译器，见 .temp/zigtool/）
python -m cmake -S pico_freertos_firmware/tests -B pico_freertos_firmware/tests/build-win -G Ninja ^
  -DCMAKE_C_COMPILER=<cc.bat 绝对路径> -DCMAKE_CXX_COMPILER=<cxx.bat 绝对路径>
python -m cmake --build pico_freertos_firmware/tests/build-win

REM 运行 16 套测试
<site-packages>\cmake\data\bin\ctest.exe --test-dir pico_freertos_firmware/tests/build-win --output-on-failure

REM 仿真渲染（本报告图片来源）
.temp/sim/showcase.exe .temp/sim/frames     REM 由仓库根目录运行，输出 18 帧 PPM
python .temp/sim/make_images.py             REM PPM → 4x PNG + 2x GIF

数据核验：所有截图产出自本云电脑实跑；ctest 输出为 16/16 Passed（2026-11-23）。渲染源码取自仓库 main 分支（a13d8dd），未做任何源码改动。
