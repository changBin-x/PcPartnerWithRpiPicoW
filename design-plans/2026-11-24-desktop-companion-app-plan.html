01产品概述

一句话定位：让用户把出厂已烧录固件的 Pico W 桌面状态屏「插上电脑就能用」的配套软件——全程零命令行、零编程、零 API Key。

目标用户画像

  • 桌搭爱好者：买了成套桌面伴侣屏硬件（出厂已烧录固件，无 WiFi 凭据），只想点亮摆在桌面/塔机侧板上
  • 不会也不愿打开终端；对「改源码、装 Python、申请 API Key」零容忍
  • 整机是普通家用 Windows（台式有线为主，笔记本无线皆可）
核心承诺（产品验收线） 从「下载安装包」到「屏幕显示自己电脑的实时状态」，不超过 5 分钟、不出现任何终端窗口、不申请任何 Key。

产品形态

  • 一个深色现代 UI 的 Windows 应用（pywebview 外壳 + HTML 前端）：仪表盘主页、设备页、四步向导、设置、诊断五块功能区
  • 托盘常驻：平时只占托盘一角（内存预算达标态），单击开窗、右键快捷菜单；关窗不退出
  • 开机自启动（注册表 HKCU Run 键，可随时关闭）——开电脑即点亮桌面屏

非目标（v1 明确不做）

  • 多设备同时管理、固件 OTA、应用内自动更新、多语言、浅色主题、局域网在线改 WiFi（详见 §11）
  • 不迁移存量编译期 secrets 用户——旧固件一切照常（v2 指标包一个字节都不动 pc_metrics/protocol.py:10-24）

04通信协议设计

4.1 端口与分发规则

所有 UDP 包共用 8765 端口。udp_listener 收包后进入两段式解析（不依赖字段顺序，不放松 v2 门禁）：

  • 先跑现有 v2 严格校验（11 字段齐全、v==2、seq 单调、范围校验）→ 通过则照旧进入 system_state_update_metrics
  • 失败且是合法 JSON → 交给新的 CTL/PRV 解析器；键 "c" 走控制命令、键 "prv" 走配网命令（仅配网模式/USB 接受）

v2 严格校验现状：pico_freertos_firmware/src/network/metrics_parser.c:200-225 · 明文无 CRC 为既有决策（README.md:339）

4.2 CTL 控制包（PC → 设备，≤128B）

{ "c":"theme", "id":2 } // 切主题 0-4；复用 system_state_set_theme + 5s 去抖落盘
{ "c":"wx", "t":9.0, "w":45, "ct":16, "city":"扬州", "ts":1764000000 } // 推天气快照
{ "c":"probe" } // 请求立即回一次 HBEAT（App 启动探测）
字段类型/范围语义
c枚举 theme/wx/probe命令名（packet 首键）
id0–4 整数主题 ID，与固件 UiThemeId 一一对应（include/ui_theme_id.h:13-20）
t / w / ct温度 ℃ / WMO 天气码 / 高德兼容天气码主机完成翻译后下发；w 供设备显示词条，t 直接显示
city / ts≤16B UTF-8 / Unix 秒城市名（App 已确保字库覆盖）／快照时间，过期走「旧」前缀语义

降级语义直接复用：推送数据老化即置 is_stale，屏幕加「旧」前缀（weather_service.c:980-991 现有行为），PC 关机后设备保留最后画面，体验与高德自抓完全一致。

4.3 HBEAT 心跳包（设备 → PC，10s / 应答式）

{ "hb":1, "th":2, "fw":"1.5.0", "rssi":-58, "mode":1 } // th=当前主题 · fw=固件版本 · rssi=WFi 信号 · mode: 0无凭据配网中 / 1已连网 / 2断线重试

最近源学习：固件当前只收不发（udp_listener.c 无发送代码），新增「记录最近合法包的源地址」作为心跳目标地址——主机探测 probe 或正在广播指标包，设备就有回程地址；若无源记录则跳过心跳（避免误广播）。这维持了「设备零配置、无 IP 发现协议」的现状哲学。

4.4 PRV 配网命令（仅 USB CDC 与 SoftAP 模式接受）

{ "prv":"set_wifi", "ssid":"Home-2.4G", "psk":"••••••", "otp":583412 } // SoftAP 通道必带 otp；USB 免
{ "prv":"scan" } // 设备侧扫描周边 WiFi 列表（SoftAP 内下发，解决 PC 用网线看不到 WiFi 的场景）
{ "prv":"info" } / { "prv":"factory_reset" } // info=USB 诊断；恢复出厂仅 USB 或长按按键
  • SoftAP：热点名 桌面伴侣-XXXX（XXXX=MAC 尾 4 位），开放网络；屏幕显示 6 位数字配对码 = 一次性热点校验码；配对码连错 5 次自动退出配网模式（需长按重新进入）
  • 凭据试连回滚：新凭据 15 秒试连失败 → 自动回滚旧凭据并在屏上提示「未连上」，绝不让设备变砖
  • USB：JSON Line（每行一条同构命令 + → 行式应答），Raspberry Pi 官方 VID 2E8A 自动识别串口，插线即认设备

无凭据现状：WiFi 宏注入（tools/sync_secrets.py:24-40）、SSID 空则任务自删（wifi_manager.c:110-120）、屏幕显示 WIFI CONFIG（README.md:211）· SoftAP 在 Pico SDK 中即 cyw43_arch_enable_ap_mode，与 STA 同栈可用 · SmartConfig/SmartConfig 类广播配网在 CYW43 无混杂模式支持，已排除（技术事实）

4.5 安全边界（明示声明，不假装）

能力谁可以防线
看广播流量（含指标与天气文字）同网段任何设备无（与现状一致：协议明文，README.md:341 已知限制）。设计文档与 App「关于」页明示
切主题 / 推天气 / 读心跳同网段任何设备影响≈物理按键按一下，接受（用户决策）
写 WiFi 凭据仅 USB 持有者；SoftAP 模式内且带配对码配对码 6 位 × 5 次机会；普通模式网络侧不监听 prv 命令
恢复出厂 / 抹凭据USB 直连 或 长按按键永不开放网络远程

单进程 python 3.11（PyInstaller 打包），一个主线程 + 三个工作线程 + pystray 托盘：

7.4 一键诊断（侧栏「诊断」页）

网络可达本地 UDP socket 实发包 + 网卡子网出口正常「正在用无线网卡发送：请确认电脑与屏幕连的是同一路由器」

7.5 文案与状态原则（零基础用户）

  • 用户侧词汇：说「暂停监控」「屏幕」，不说「UDP 广播」「进程」；技术词进「高级设置」和诊断详情
  • 动词按钮：按钮写结果——「保存并同步到屏幕」，不写「提交」
  • 错误必给出口：每条错误文案第二句就是下一步动作；禁止只有一个红色感叹号
  • 同步诚实：主题/天气发送后由心跳确认才显示「已同步 ✓」，不确认就显示「待同步」，绝不假成功
